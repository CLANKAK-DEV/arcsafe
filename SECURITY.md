# Security policy

## Supported version

Only the latest commit on `main` is supported. Testnet deployments are
demonstration software and have not received a third-party audit.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's
[private vulnerability reporting](https://github.com/CLANKAK-DEV/arcsafe/security/advisories/new)
and include the affected component, reproduction steps, impact, and any known
mitigation.

Please allow a reasonable remediation window before public disclosure. Never
include private keys, seed phrases, funded-wallet credentials, or sensitive
user data in a report.

## Scope

Reports about the contracts, deployment scripts, verified factory registry,
wallet interaction, transaction simulation, and hosted frontend are in scope.
The Arc Network and third-party wallet or RPC implementations are maintained
by their respective providers.
